# India Trade Analytics Dashboard

## Project Overview
An interactive Power BI project analyzing India's exports and imports with 10 major trading partners from 2010 to 2023.

## Objectives
- Compare India's exports and imports over time.
- Analyze trade relationships with major partner countries.
- Identify trends across trading partners and product categories.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- UN Comtrade trade data

## Key Features
- Import and export analysis
- Country-wise trade comparison
- Year-wise trends
- Product category analysis
- Interactive filters and slicers
